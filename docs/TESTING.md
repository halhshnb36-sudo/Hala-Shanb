# قائمة الاختبار

ضعي علامة ✓ بعد التجربة الفعلية. هذه القائمة لم تُنفَّذ بعد (انظري تنبيه الحالة في README).

## 0) البناء
- [ ] `npm install` ينتهي دون أخطاء.
- [ ] `npm run typecheck` بلا أخطاء.
- [ ] `npm run build` ينتهي بنجاح وينشئ `dist/`.
- [ ] `npm run cf:dev` يشغّل الموقع محليًا عبر wrangler ويعمل التوجيه المباشر.

## 1) قاعدة البيانات والأمان (Supabase SQL Editor)
- [ ] الملفات 001 → 006 تعمل بلا أخطاء.
- [ ] وجود الحاويات الأربع في Storage، و`videos` خاصة.
- [ ] RLS مفعّل على الجداول الخمسة (Table Editor → RLS enabled).
- [ ] كزائر (anon، مثلًا من نافذة خاصة): `select * from articles` يُرجع المنشور فقط.
- [ ] كزائر: محاولة `insert`/`update`/`delete` على `articles` و`media` و`site_settings` تُرفض.
- [ ] كزائر: `select * from content_views` لا يُرجع شيئًا، و`insert` يُرفض.
- [ ] مستخدم مسجّل غير مدير: لا يستطيع التعديل ولا الرفع ولا استدعاء `admin_stats`.
- [ ] رفع ملف إلى حاوية من حساب غير مدير يُرفض.

## 2) الموقع العام
- [ ] الصفحة الرئيسية تفتح دون تسجيل دخول، والشعار ظاهر في الرأس والواجهة والتذييل.
- [ ] العنوان «هالة شنب للعناية بالشعر» والشعار التسويقي ظاهران.
- [ ] `/biography` يعرض السيرة كاملة بعناوينها العشرة وبترتيبها، وفي آخرها الشعار التسويقي.
- [ ] الروابط المباشرة `/biography` `/articles` `/gallery` `/videos` `/contact` `/admin` تعمل عند إعادة التحميل.
- [ ] رابط غير موجود يعرض صفحة 404، وحالة HTTP فعلًا 404 (`curl -I`).
- [ ] الأقسام الفارغة تعرض رسالة «لا يوجد محتوى» وليس صفحة بيضاء.
- [ ] الموقع سليم على الجوال (عرض 375px) وعلى الشاشات الكبيرة، والاتجاه RTL صحيح.
- [ ] أيقونات التواصل لا تظهر وهي معطّلة، وتظهر بعد التفعيل مع رابط صحيح.
- [ ] رقم الهاتف يفتح الاتصال، وزر واتساب (بعد التفعيل) يفتح `wa.me/20111…`.

## 3) تسجيل الدخول
- [ ] `/admin` بدون تسجيل يحوّل إلى `/admin/login`.
- [ ] بيانات خاطئة تعرض رسالة خطأ.
- [ ] حساب موجود في Auth لكنه ليس في `profiles` يظهر له «غير مصرّح».
- [ ] المدير يدخل ويصل للوحة، وتسجيل الخروج يعمل.

## 4) المقالات
- [ ] إنشاء مقال كمسودة: لا يظهر للزوّار.
- [ ] النشر: يظهر في الرئيسية وصفحة المقالات ويُفتح برابطه.
- [ ] إلغاء النشر: يختفي من الموقع العام فورًا.
- [ ] التمييز يرفع المقال لأول القائمة.
- [ ] غلاف + صور إضافية + فيديو (رابط يوتيوب، ثم ملف مرفوع) تظهر في صفحة المقال.
- [ ] المعاينة قبل النشر تعرض الشكل النهائي.
- [ ] الحذف يطلب تأكيدًا ثم يحذف المقال وملفاته.
- [ ] البحث والتصفية والترقيم (أكثر من 10 مقالات).
- [ ] قطع الإنترنت أثناء الحفظ: تظهر رسالة، وتبقى البيانات في النموذج، وتنجح إعادة المحاولة.
- [ ] إغلاق الصفحة وفيها تعديلات غير محفوظة ثم إعادة فتحها يعرض «استعادة».
- [ ] `/admin/biography`: تعديل النص يظهر في `/biography` بعد الحفظ.

## 5) الصور
- [ ] رفع عدة صور دفعة واحدة، وتظهر بالترتيب (الأحدث أولًا).
- [ ] صورة أكبر من 15 م.ب أو بصيغة غير مسموحة تُرفض برسالة واضحة.
- [ ] تعديل العنوان والوصف، واستبدال الصورة، وإلغاء النشر، والتمييز، والحذف بتأكيد.
- [ ] تقديم/تأخير يغيّر ترتيب العرض في الموقع.
- [ ] العرض المكبّر: Esc، الأسهم، الجوال.

## 6) الفيديو
- [ ] رفع ملف MP4 صغير، ثم ملف أكبر من 6 م.ب (رفع متقطّع مع شريط تقدّم).
- [ ] قطع الاتصال أثناء رفع كبير ثم إعادة المحاولة: يستأنف الرفع.
- [ ] إضافة رابط يوتيوب، وصورة مصغّرة مخصّصة.
- [ ] التشغيل في الموقع (ملف مرفوع + رابط يوتيوب).
- [ ] فيديو غير منشور لا يمكن لزائر الحصول على رابط تشغيله.
- [ ] استبدال الفيديو وتعديل بياناته وحذفه (يُحذف الملف من التخزين).

## 7) التحليلات
- [ ] فتح مقال كزائر (نافذة خاصة) يزيد عدّاد المقال بمقدار 1 فقط، وإعادة التحميل المتكررة لا تزيده خلال 30 دقيقة.
- [ ] فتح `/biography` يزيد «مشاهدات السيرة».
- [ ] فتح صورة في العرض المكبّر يزيد مشاهدات تلك الصورة تحديدًا، ومجرّد التمرير على الشبكة لا يزيد.
- [ ] تشغيل فيديو يزيد تشغيلاته بعد بدء التشغيل فقط.
- [ ] فلاتر اليوم / 7 أيام / 30 يومًا / الكل تعطي أرقامًا صحيحة (قارني مع `select count(*) from content_views`).
- [ ] قوائم «الأكثر مشاهدة» تعرض العنصر الصحيح.
- [ ] زيارة المحتوى وأنتِ مسجّلة دخول كمدير لا تُحتسب.
- [ ] من الكونسول: `supabase.from('content_views').insert(...)` يُرفض، و`rpc('track_view')` لمحتوى غير منشور يُرجع false ولا يسجّل.

## 8) الإعدادات
- [ ] تغيير الاسم والشعار التسويقي والهاتف والعنوان يظهر في الموقع.
- [ ] رفع شعار جديد يستبدل الشعار، و«العودة للافتراضي» يعيد الشعار الأصلي.
- [ ] روابط فيسبوك/إنستجرام: رابط غير صحيح يُرفض، وتفعيل بلا رابط يُرفض.
- [ ] ترتيب أقسام الصفحة الرئيسية وإخفاء قسم وتغيير عناوينها.
- [ ] تعديل بطاقات الخدمات وصورة الواجهة واللون الرئيسي.

## 9) النشر
- [ ] النشر على Cloudflare ينجح والرابط يعمل بـ HTTPS.
- [ ] متغيرات `VITE_*` موجودة في Cloudflare، ولا يوجد أي سر في المستودع.
- [ ] كل بنود الأقسام 2–8 تعمل على الرابط المنشور.
- [ ] (اختياري) ربط دومين مخصّص.
